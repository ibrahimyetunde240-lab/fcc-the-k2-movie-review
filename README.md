# The K2 Movie Review

A personalized movie review page for the Korean drama *The K2*, built with HTML as part of the freeCodeCamp Responsive Web Design curriculum.

## Overview

This project is a simple movie review page featuring an introduction to *The K2*, its rating, and a list of its main cast members.

## Features

- Movie title and review
- Movie poster image with alternative text
- Movie rating
- Main cast members and their roles
- Semantic HTML structure
- Accessible image alternative text

## Technologies Used

- HTML5

## What I Learned

Through this project, I practiced:

- Structuring content with semantic HTML
- Adding images with meaningful alternative text
- Using headings and lists to organize information
- Using `aria-hidden` for decorative rating stars
- Creating a simple, accessible content page
